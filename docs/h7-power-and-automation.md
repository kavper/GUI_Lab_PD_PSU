# Power and automation controls

The global header POWER OFF stops output and automation, then sends binary TEXT_CMD `BMS SHUTDOWN` to G4. This requests BQ76922 shutdown; waking uses TS2 according to the G4 contract. The main TURN ON/OFF toggle controls the PSU output. These actions are distinct. The duplicate Battery shutdown button was removed. Queue failure, NACK or timeout reports failure instead of leaving an irreversible local ON block. No failed command restarts output.

Main header displays BAT PWR (signed net battery power from valid TB pack voltage/current) and VPREREG (G4 METER DCDC output rail). These use independent freshness checks; neither is an invented total power consumption. USB input measurements remain on the USB-C page. Power snippets were removed from the setpoint cards.

External charger admission uses normal H7 ON readiness and manual chemistry/cell/polarity confirmation. OFF has no physical PERMIT; H7 does not force it. After operator connection/polarity confirmation, charging sends pack CV with the operator-selected current limit even if the OFF ADC reports zero. It does not wait indefinitely for voltage that may be visible only after startup. It waits for SET ACK and G0 readback, then requests ON. STARTING waits for physical PERMIT and output confirmation for at most 5 seconds. Active-phase PERMIT/output loss stops charging. Hardware operation is not established by host tests.

Sequence GUI provides integer cycle count 1..65535, -1/+1 and explicit CONTINUOUS. RUN starts the first enabled KEEP step as ON; later KEEP steps retain the output state. SET ACK/readback precedes ON. Ramps start from the preceding voltage, in either direction, and preserve it across steps/loops. Zero slew means an immediate change. Step duration is dwell after the ramp reaches its target with readback/output confirmation; G4/G0 startup has a 5-second timeout. Configuration is locked while running or paused. Empty enabled-step lists are rejected. Continuous run requires explicit STOP or is cancelled by fault/shutdown; never resumes automatically.

Validation: tests/run_host_tests.ps1 (binary protocol, application startup, charger/sequence lifecycle, voltage/gauge display) and opt-in PSU_USB_SELFTEST (main power labels, cycle keypad, continuous control, full header shutdown, existing gauge tests). Generate and both Designer compile paths use the executable project. No hardware flashing occurs during these checks.

Pack target voltage is separately editable, e.g. 4S Li-ion at 16.400 V, below the default 16.800 V. Changing chemistry/cell count resets the override. Targets outside the chemistry range are rejected; a measured pack above target is not deliberately discharged. Lead float never exceeds the selected target.

Sequence keypad widgets and their themed surfaces stay in the same container, so dark/light themes, animations and visibility apply together. Simulator screenshots cover both themes and actual 4S target keypad entry. Regression tests cover 0 -> 5 -> 0 V at 1 V/s and binary charger startup with zero OFF voltage.

H7 can remain powered by an independent supply after POWER OFF. The BMS shutdown request is diagnostic status, not a persistent SET/ON lock. Settings remain editable; manual ON uses normal fresh METER/G0 readiness, OFF confirmation and G4/G0 fault checks. Actual BMS wake requirements still belong to the hardware. Shutdown stops automation and never restarts output; fresh data alone cannot restart it. The Battery page shutdown notice expires normally.

Charger setup consists of chemistry, series cells, target pack V, charge A and stop-below A. Capacity entry and its implicit 0.5C ceiling are removed; legacy profile fields are retained for source compatibility only. Operator charge current is bounded by hardware limits and is sent from startup. Session feedback shows measured current and commanded limit. Stop-below current is only a CV completion criterion after confirmed SET and target voltage. Text updates invalidate old and new bounds to erase prior wider readouts.

External charger no longer uses a PRECHARGE phase: it sends the operator charge limit from the initial SET, waits for ACK/readback, starts G4, then enters CC. Historical precharge profile fields/state values remain for compatibility only. Session has live voltage/current with matching blue/green traces, numeric left/right axes, and elapsed time ticks. Independent 1/2/5 scales add 20% headroom and retain peak ranges through trace decimation until a new session; time axis expands automatically. Stale live telemetry displays dashes. Target/current/end settings and delivered charge/energy remain visible with STOP accessible on Session. Simulator fixtures exercise both themes and scale expansion to 3.2 A; these are not hardware verification.

Session time scaling is now continuous (full elapsed time plus 10% headroom, minimum 10 s), so crossing minute/range boundaries does not suddenly compress the history. Session refresh runs every two TouchGFX ticks; a live tail connects the most recent history sample to fresh measured voltage/current. Historical samples and actual live values are not filtered or delayed. Live tail is suppressed on stale telemetry or stopped sessions. UI regression checks former range boundaries for at most one pixel displacement per 16 ms.

Both Y axes now fit the minimum and maximum of all visible history samples plus fresh live values, with independent voltage/current ranges and padding. Lower bounds can rise above zero when all measurements are above zero. Outward bounds expand immediately; inward bounds require an unchanged candidate for five seconds. New sessions reset the ranges; zero and constant signals retain a finite span. All visible history remains within bounds.

SESSION STOP enablement is refreshed on every page, including after SETUP starts charging and switches to SESSION. Previously its enablement was updated only on SETUP, leaving the visible session button untouchable. STOP now invokes application shutdown, stops charging, and queues explicit G4 OFF even if the charger is no longer running but the output remains active. Simulator regression dispatches a real press/release through the session view and checks both charger cancellation and the transmitted OFF frame.
